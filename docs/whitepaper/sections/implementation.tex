%% 5.1 System Requirements

reasoning-core has minimal system requirements:

\begin{itemize}
    \item Python 3.11+
    \item ~250MB disk space for Mamba checkpoint
    \item ~200MB RAM for model inference
    \item CPU (no GPU required)
    \item Supported operating systems: macOS, Linux, Windows (WSL)
\end{itemize}

%% 5.2 Installation

\begin{lstlisting}[language=bash, caption={Installation Commands}]
git clone https://github.com/jakubkrzysztofsikora/reasoning-core.git
cd reasoning-core
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
huggingface-cli download state-spaces/mamba-130m-hf
\end{lstlisting}

%% 5.3 Dependencies

Key dependencies include:

\begin{itemize}
    \item tree-sitter: For AST parsing
    \item transformers: HuggingFace integration
    \item fastapi: HTTP service
    \item uvicorn: ASGI server
    \item torch: PyTorch (CPU only)
    \item mamba-ssm: Mamba implementation
\end{itemize}

%% 5.5 Sidecar Service

The sidecar service (src/s2_core.py) is a FastAPI application that can be started with:

\begin{lstlisting}[language=bash, caption={Starting the Sidecar}]
python3 -m src.s2_core
# or
bash scripts/start-sidecar.sh
\end{lstlisting}

The service listens on 127.0.0.1:8765 by default.

%% 5.6 Hook Configuration

Hooks are configured in .claude/settings.json (for Claude Code) and similar configuration files for other CLIs.

%% 5.7 Supervisor

The supervisor (src/sidecar_supervisor.py) ensures the sidecar remains available with automatic restart on crash and launchd/systemd integration.
